# Changelog

## [1.0.5] - 2026-11-24

### Changed

- Moved default importer override enable switches to the asset importer manager.
- Disabled default importer override properties when their corresponding switch is off.

## [1.0.4] - 2026-11-24

### Changed

- Synchronized the shared editor utility implementations with the EZUnity source files.

## [1.0.3] - 2026-11-20

### Changed

- Removed the migrated Hierarchy Active Toggle editor extension and its documentation image.

## [1.0.2] - 2026-11-19

### Added

- Added the EZProjectSettings sample content and registered it in `package.json`.
- Merged the original demo documentation into the package README files.
- Moved sample screenshots to `Documentation~/Images`.

### Changed

- Removed `EZEditorSettings`; the Hierarchy Active Toggle is now provided by EZEditorTools as an editor-local preference.

## [1.0.1] - 2026-11-19

### Documentation

- Improved the Chinese and English README descriptions.
- Documented the Project Settings entry path.
- Clarified Graphics Settings and Asset Importer Preset functionality.
